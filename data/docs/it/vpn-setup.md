# VPN Setup and Troubleshooting

1. Install the Acme VPN client from the software portal.
2. Sign in with your corporate account and approve the MFA prompt.
3. If the VPN keeps disconnecting, switch protocol to IKEv2 and update the client.
4. Still failing? Open a helpdesk ticket with the error code and your OS version.

Known issue: VPN drops on hotel Wi-Fi; use the phone hotspot as a workaround.
